About the channel

ZZZZ Tower is a YouTube Shorts channel of "what if" simulations: what would happen if the air vanished for five seconds, if the Earth stopped spinning, if gravity doubled for a day. Each short takes one impossible premise and plays it out in under a minute. The scenarios are fictional entertainment loosely based on science, not scientific predictions. Narration is AI-generated (Google Gemini), and visuals are made with AI, code and 3D computer graphics.

ZZZZ Tower Uploader

ZZZZ Tower Uploader is a personal tool used only by the channel owner to upload videos to the owner's own YouTube channel. It runs locally on the owner's computer and is not distributed to the public.

This tool uses YouTube API Services. With the permission granted through the owner's Google account, it only:

  • uploads videos (always as private) and sets their title, description and tags
  • sets thumbnail images
  • reads the channel name and ID to confirm the upload destination

See the Privacy Policy for how data is handled.

チャンネルについて（日本語）

「ZZZZ Tower」は、「もしも空気が5秒間消えたら？」「もしも地球の自転が止まったら？」のような、ありえない「もしも」を AI シミュレーションで映像化する YouTube ショートのチャンネルです。1本1テーマ、1分以内で「その瞬間、世界はどうなるか」を見せます。内容は科学をヒントにしたエンタメとしての架空のシミュレーションで、実際の予測ではありません。ナレーションは AI 音声（Google Gemini）、映像は AI・プログラム・3DCG で作っています。

投稿ツール（ZZZZ Tower Uploader）は、運営者が自分のチャンネルへ動画を投稿するためだけに使う個人用のツールです。運営者のパソコン上でのみ動作し、一般には公開・配布していません。YouTube API サービスを利用し、動画のアップロード（常に非公開）と設定、サムネイルの設定、投稿先チャンネルの名前と ID の確認だけを行います。
