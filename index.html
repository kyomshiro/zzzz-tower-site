About the channel

ZZZZ Tower is a YouTube Shorts channel of "what if" simulations set at Zedmouth International Airport (ZZZZ), an airport that does not exist. What if the tower cleared every aircraft to land on the same runway at once? What if it told a jet to land backwards? Each short takes one impossible ATC instruction and plays out what would happen, in under a minute. The phraseology sounds real; the instructions do not. All airports, airlines and callsigns are fictional, and the scenarios are entertainment, not real aviation procedures. There is no narration: the radio voices are AI-generated (Google Gemini), and visuals are made with code and 3D computer graphics. Any shot that uses AI-generated video is disclosed in that video's description.

ZZZZ Tower Uploader

ZZZZ Tower Uploader is a personal tool used only by the channel owner to upload videos to the owner's own YouTube channel. It runs locally on the owner's computer and is not distributed to the public.

This tool uses YouTube API Services. With the permission granted through the owner's Google account, it only:

  • uploads videos (always as private) and sets their title, description and tags
  • sets thumbnail images
  • reads the channel name and ID to confirm the upload destination

See the Privacy Policy for how data is handled.

チャンネルについて（日本語）

「ZZZZ Tower」は、存在しない空港 Zedmouth International（ZZZZ）を舞台に、「もしも管制官が全機に同じ滑走路への同時着陸を許可したら？」「もしも『後ろ向きで着陸せよ』と指示したら？」のような、ありえない管制指示の「その後」を 3DCG のシミュレーションで映像化する YouTube ショートのチャンネルです。1本1指示、1分以内で見せます。言い回しは本物そっくり、指示の中身だけがありえません。空港・航空会社・便名はすべて架空で、内容はエンタメであり実際の航空の手順ではありません。ナレーションはありません。無線の声は AI 音声（Google Gemini）、映像はプログラムと3DCGで作っています。AI 生成の映像を使ったカットがある場合は、その動画の説明欄でお知らせします。

投稿ツール（ZZZZ Tower Uploader）は、運営者が自分のチャンネルへ動画を投稿するためだけに使う個人用のツールです。運営者のパソコン上でのみ動作し、一般には公開・配布していません。YouTube API サービスを利用し、動画のアップロード（常に非公開）と設定、サムネイルの設定、投稿先チャンネルの名前と ID の確認だけを行います。
