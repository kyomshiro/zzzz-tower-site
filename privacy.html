HomeTerms of Service

ZZZZ Tower Uploader ("the tool") is a personal tool used only by the owner of the YouTube channel ZZZZ Tower to upload the channel's own videos. It runs locally on the owner's computer and is not offered to anyone else.

Information the tool accesses

  • YouTube Data API with two scopes: youtube.upload (upload videos and thumbnails) and youtube.readonly (read the signed-in channel's name and ID to confirm the upload destination).
  • The tool reads only the signed-in channel's name and ID. It does not access, collect or modify any other user's data.

How information is stored and shared

  • The OAuth token is stored only on the owner's computer and is sent to no server other than Google's.
  • No information is shared with, or sold to, any third party.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/connections, or with the tool's revoke command, which also deletes the locally stored token.

YouTube and Google

This tool uses YouTube API Services. Use of the tool is also subject to the YouTube Terms of Service and the Google Privacy Policy. The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
